# Scarab TEA Simulation Command

Build and run the Scarab simulator with TEA configuration.

## Instructions

Execute the following steps in order:

1. **Build Scarab**
   ```bash
   cd ~/scarab-infra && ./sci --build-scarab tea_dbg
   ```

2. **Run Simulation**
   ```bash
   cd ~/scarab-infra && ./sci --sim tea_dbg
   ```

After completion, report the build and simulation status to the user.
